# 走走｜产品决策

## 定位与优先级

- 产品：以旅行为核心的 AI 生活出行 App；周末、约会、聚餐复用同一规划能力。
- 旗舰闭环：模糊想法 → 理解 → 方案 → 多人决策 → 执行 → 记录 → 回放 → 分享 → 复用。
- 用户：需要和朋友快速达成旅行共识、执行并沉淀真实经验的年轻用户。

## 已锁定决策

- 品牌名固定为「走走」；AI 隐于底层，不作为品牌前缀。
- 首次注册只收头像和昵称；首次启动不申请定位、不做偏好问卷。
- 首页固定：上海、天气、头像、旅行/周末/约会/聚餐、单一动态模块。
- Bottom Tab 固定：`首页｜行程｜社区｜我`；没有中央加号或第五项。
- 旅行输入固定为自然语言 + 多截图；只补问不确定项；生成三套方案并局部编辑。
- 多人统一称「朋友」；每人一票；路线偏离必须人工确认。
- 行程视觉固定为 2D 平面 + 3D 小人 + 简化地点，不做完整 3D 城市。
- 社区卡片先进入自动回放，再过渡到图文详情；可以复用他人路线骨架。
- 当前是 Local Interactive Product Prototype，不声称具备实时地图、天气、开放时间或交易能力。

## 明确不做

聊天、支付、排队拥挤、精确朋友位置、长推荐流、首次偏好问卷、完整 3D 城市、AI 紫蓝视觉。
