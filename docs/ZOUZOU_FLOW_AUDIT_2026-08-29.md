## 本轮发现并固化的规则

1. 嵌入式展示壳不能让安全区跟随同一个滚动容器。现在外壳固定 874px，`.app-page` 在 72px 安全区之后独立滚动；行程标题在点按自动滚动后仍停在安全区下方。
2. 城市切换必须走全局 `city` 源；社区不能保留自己的孤立城市副本。切换后内容密度也必须达标，不能只剩一张卡片造成大面积空白。
3. 地图是路线的上下文，不是整页背景：实时行程固定约 360px，完整路线常驻，播放只改变 Bot/进度，不改变镜头。
4. 社区地图开关只能影响社区回放；行程地图是核心任务的一部分，不提供关闭入口。
5. 任何 Bot Marker 都不能带黑色方形底；Bloub/Grok 风格 SVG 与地图之间只保留轻微投影。
6. 长页面的底部导航保留安全区空间；社区顶部 Header 不使用 sticky，行程 Header 可在独立滚动层内保持上下文。

## 边界与后续

- 当前环境没有高德 Key，预览使用带归属的低饱和 OSM fallback；配置 `VITE_AMAP_KEY` 与 `VITE_AMAP_SECURITY_KEY` 后会优先使用高德 provider。
- 路线地点仍是本地演示数据，城市切换同步的是产品上下文与内容，不会伪造杭州真实路线坐标。
- 本机网络曾无法稳定请求 Carto 瓦片，因此没有把不可用的 Carto URL 留在生产路径；如需替换，必须先做离线/失败态回归。
