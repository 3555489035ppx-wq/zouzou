# 在手机使用走走

**本说明对应尚未正式发布的手机版本。2026-09-14仍有发布阻塞，不要把现有站点当作已验收新版。** 现有域名是 https://zouzou.ppx.wiki ，本轮未更新；云端保存、生成与新分享功能尚未在该域名验证。

## 完成发布后如何添加桌面

iPhone：在Safari打开正式地址，点分享→添加到主屏幕；若出现“作为网页App打开”则开启，确认名称“走走”及走走图标后添加。已有安装窗口不应反复要求安装。

Android：在支持的Chrome等浏览器中，点击页面提供的安装按钮或浏览器菜单里的“安装应用 / 添加到主屏幕”。浏览器不提供安装提示时，仍可直接在网页使用；并非所有浏览器能力相同。

微信或QQ内打不开安装/地图时，使用右上角菜单在Safari或系统浏览器打开。走走内入口：“我的→添加到手机桌面”。不要使用localhost、局域网地址或临时测试链接发给朋友。

## 保存和访客身份

当前实现先把选用行程保存为本机副本。“我的行程→本机行程与云端保存”可明确上传；只有看到服务器确认才表示云端保存完成，失败时本机原记录保留。读取云端会补入缺失的行程，不擅自覆盖本机同ID版本。

没有配置手机号/微信/Apple登录。访客身份依赖当前浏览器Cookie，期限30天；清除Cookie、退出、换设备或浏览器/桌面窗口隔离时不能保证找回私人行程。先使用设置中的本机备份，且妥善保管其中的私人信息。朋友查看有效分享不需要登录GitHub或Cloudflare。

## 分享给朋友

保存行程→进入分享工具→选择1/7/30天期限→预览要分享的活动、地址及预算→确认创建→点击“发送给朋友”或复制链接。分享是只读快照，不是向发现广场公开；持链接者可转发。

请人工确认活动地址不含私人住址。系统会排除住宿、到达/返程、原截图、私人备注等字段，但不能代替你检查自由输入的内容。

取消系统分享是正常操作，链接仍有效。系统面板打开或复制完成不表示朋友已收到；请让朋友实际打开核对城市和日期。剪贴板失败时长按链接或展开摘要手动复制。

修改原行程不会自动改变朋友看到的快照；需要点“将此链接更新为当前行程”。在创建者窗口可撤销；撤销无法收回朋友已复制、下载或截图的内容。过期或撤销后重新读取应显示失效，离线时不提供正文兜底。

## 使用地图

在地点旁点击地图按钮，选择苹果地图、高德或百度；看清完整城市、分店及地址后再导航。未知或未确认坐标使用文字搜索，不以城市中心冒充精确位置。多日行程保留在走走，逐站打开地图；不承诺完整多点路线已导入地图App。

走走不要求先授权定位才能搜索目的地；外部地图可自行请求当前位置。未安装App时可能打开地图网页，可复制已知完整地点信息。内置浏览器拦截时换系统浏览器；回到走走后核对仍是原来的行程。

## 更新、断网与错误

出现新版提示时可先准备更新，保存当前输入后重新打开。不要为了升级手动清除浏览器数据。离线不能AI生成、云端保存或创建分享；出现提示后恢复网络重试。看到“知识尚未获准发布”不是网络错误，当前版本不应被当作正式生成服务。

记录日期、地区、运营商、设备、系统/浏览器版本和每步耗时；不要在公开报告放私人行程、访问令牌或完整私密分享URL。当前电脑的HTTPS访问结果不能替代这些测试。
