# 走走｜User Flows（用户流程）

## A｜首次进入

启动 → 登录方式 → 手机号/验证码 → 上传头像 → 昵称 → 首页。

## B｜旅行规划

旅行入口 → 描述与截图 → listening/reading/thinking → 核心理解卡 → 补问 → planning → 三方案 → 方案详情 → 局部替换 → 邀请朋友 → 意见汇总 → 投票 → 保存。

Human-in-the-loop（人在回路）：理解结果确认、局部替换、投票结束与保存均由用户触发。

## C｜行程执行

行程 Tab → 开始 → 3D 小人沿 2D 路线移动 → 到站 → 下一地点 → 模拟偏离 → 继续/更新 → 完成 → 自动回放。

## D｜分享与复用

发布 → 社区 Feed → 点击卡片 → 全屏自动回放 → 场景缩小进入详情 → 喜欢/收藏/评论 → 使用这个行程 → 保留骨架或偏好优化。
