## Notice rules

1. If a source file is copied or materially adapted, add the upstream copyright
   and license notice beside the adapted module or keep a precise entry here.
2. Do not copy `.env` values, OAuth client secrets, API keys, user data, hosted
   images, videos, screenshots, or brand lockups from any snapshot.
3. A permissive code license does not grant trademark rights. This is especially
   important for Simple Icons provider marks and Bloub's x.ai/Grok likeness.
4. For Simple Icons, inspect `data/simple-icons.json` for each selected icon's
   source or additional license metadata; collection-level CC0 is not a waiver
   of third-party marks or brand guidelines.
5. `react-masonry-css` remains a normal dependency boundary. If its source is
   vendored later, retain the MIT notice; package usage alone does not require
   copying the implementation into `src`.
