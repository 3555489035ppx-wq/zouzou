# 走走｜Design System（设计系统）

## 视觉

- 内容背景固定纯白；正文近黑；辅助文字中性灰；边界极浅灰。
- UI 不依赖品牌色，真实自然照片承担主要色彩。
- 标题使用圆润字形，正文使用 iOS 兼容系统栈；不打包 SF Pro 或 SF Symbols 资产。
- 图标统一使用一套线性语言，品牌走路小人使用原创 SVG。

## Tokens

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 40 / 64。
- 圆角：10 / 14 / 18 / 22 / 26。
- 字号参考：34/28/22/20/17/13/12。
- 触控：所有高频控件最小 44 × 44 CSS px。

## 组件

`ZouTabBar`、`ZouNavigationBar`、`ZouButton`、`ZouCard`、`ZouAvatar`、`ZouAvatarStack`、`ZouBottomSheet`、`ZouSegmentedControl`、`ZouPlaceCard`、`ZouPlanCard`、`ZouCommunityCard`、`ZouSearchBar`、`ZouDaySelector`、`ZouMotionBot`、`ZouTripCharacter`、`ZouLocationNode`、`ZouPhotoCarousel`、`ZouToast`。
