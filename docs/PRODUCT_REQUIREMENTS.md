# 走走｜产品需求

## P0

1. 登录与资料：启动、登录、验证码、头像、昵称、头像全局同步。
2. 首页：城市 Sheet、四入口、通知、动态行程卡、四 Tab。
3. 旅行：文本/多截图、理解进度、理解卡、补问、规划、三方案、日程编辑、局部替换。
4. 朋友：邀请、状态头像、意见汇总、投票、保存。
5. 行程：Day 切换、2D 路线、3D 小人和地点、到达、偏离确认、完成、回放。
6. 社区：双列自然比例 Feed、搜索、回放、详情、关注、喜欢、收藏、评论、使用行程、发布。
7. 我的：获赞/关注/粉丝；行程/发布/收藏/喜欢；资料与 Reduce Motion 设置。
8. `__demo`：直接进入核心页面与状态。

## 验收

- 四条主 Flow 可连续点击；刷新路由可恢复页面。
- TypeScript 与 production build 通过；核心 Smoke Tests 通过。
- 393 × 852 为主视口，同时 320/375/414/768 无横向溢出。
- 动效可中断，减少动态效果后流程完整且无大范围位移。
