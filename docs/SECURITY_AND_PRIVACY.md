# 走走｜安全与隐私

## 当前边界

- AI 密钥只在本地 BFF 的服务端环境变量读取；前端不读取 OpenAI、DeepSeek 或视觉模型密钥。
- `VITE_AMAP_KEY` 和安全密钥属于浏览器地图 SDK 所需的公开运行时配置，只能使用域名/来源限制和额度限制后的前端 Key；真实密钥不进入仓库或报告。
- 截图请求限制数量、单项大小和请求体大小；服务端只保存清洗后的元数据/事实，不把浏览器 blob/data URL 回显到文本理解请求。
- 分析事件对正文、URL、联系方式、地址和坐标字段做过滤。
- 本地存储和本地 SQLite 都属于开发/演示数据，用户应在共享设备上主动清理。

## 仍需生产化

正式账号、短信验证码、云数据库访问控制、对象存储签名 URL、服务端鉴权、速率限制、审计日志、密钥轮换、数据导出/删除和 Sentry 脱敏仍是上线前必做项。
