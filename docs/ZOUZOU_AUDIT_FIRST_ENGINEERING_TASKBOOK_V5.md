## 1. 目标和成功定义

### 1.1 产品闭环

走走是一个以旅行为核心、把模糊想法变成可执行行程、让朋友共同决定、真实执行、回放、发布并复用的本地交互原型：

```text
登录/资料 → 首页 → 创建旅行 → AI理解 → 三套方案 → 朋友/投票
→ 保存行程 → 2D地图+路线角色执行 → 到站/完成 → 社区回放
→ 图文详情 → 喜欢/收藏/关注 → 使用这个行程 → 我的
```

### 1.2 这次必须修好的用户感受

- 系统状态栏、Dynamic Island、App Header、头像永不互相覆盖。
- 用户一眼知道“我在哪个页面、下一步是什么、现在是否已生效”。
- 地图加载、缩放、跟随和路线角色移动是连续的真实状态，不是视频或页面重挂载造成的闪烁。
- Bot 是已提供的 bloub/Grok Bot 形态；Bot 的眼睛能对准当前交互目标。路线上的移动角色与助手 Bot 分离，不再混为一个随机图标。
- 社区内容既能看路线也能看图文；用户可以跳过回放、直接看详情；使用、喜欢、收藏、关注都有即时而清晰的反馈。
- “我的”中的行程、发布、收藏、喜欢都可打开对应详情，不是看得到但点不开的静态网格。
- 页面只保留一个主要黑色 CTA，其余动作降级为轻按钮或图标；文字、字号、行高、密度符合手机应用而不是桌面面板。

## 5. 产品与技术决策（执行前固定）

### 5.1 设备和壳层

- 设计基准：402×874 CSS px；真实 iPhone 17 Pro 风格壳层：圆角、窄边框、Dynamic Island、9:41、Signal/Wi‑Fi/Battery、Home Indicator。
- 用 CSS `env(safe-area-inset-top/bottom)` 和 App 内部 `safeTop/safeBottom` 双层 token；状态栏是壳层装饰，不能让页面内容伪造覆盖。
- 只保留 `首页｜行程｜社区｜我` 四栏，不新增第五栏或中央加号。

### 5.2 地图 provider

- 目标 provider：**高德 JS API 2.0**，通过 `src/services/amap/` 适配器加载；保留 provider interface，方便离线测试和未来替换。
- key 仅存 `.env.local`/本地运行环境，禁止提交、截图、前端日志泄露。
- 地图初始化一次，路线/节点/角色通过数据层更新；禁止在 React render、Day 切换或播放 tick 中 destroy/create map。
- 必须使用 `fitBounds` 等价的高德 camera 计算，首屏覆盖当天完整路线；局部播放先锁定两节点范围再移动。

### 5.3 Bot 和路线角色

```text
AssistantBot (bloub/Grok)
  用途：AI理解/规划、空状态、交互注视
  来源：src/private-assets/bloub/bot/*
  约束：纯时间采样、可中断、眼睛跟随 gazeTarget

RouteCharacter (走走路线角色)
  用途：2D地图上的武康路→安福路等路线移动
  约束：独立 DOM/SVG/Canvas layer，沿 LineString 按距离移动
```

不要把 bloub 直接当作地图上的路线角色，也不要再生成第三套随机机器人。

### 5.4 动效 token

- instant：100ms（按压、颜色、Tab）
- quick：160ms（局部状态）
- standard：260ms（Sheet/局部内容）
- context：380ms（页面上下文）
- hero：550ms（回放→详情 shared element）
- 地图相机：450–650ms；路线角色单段：1.8–3.0s；超出时必须有进度状态。
- 只动画 transform/opacity；禁止无限装饰动画、过度 bounce 和假视频；状态中断从当前帧继续。

### 5.5 设计系统

建立并让所有页面消费同一套 tokens：

- Typography：标题/正文/辅助/按钮字号、字重、行高；中文不靠挤压换行。
- Spacing：4/8/12/16/24/32/40/64。
- Radius：10/14/18/22/26。
- Color：近黑正文、中性灰辅助、极浅边界、白 surface、喜欢红色；黑色 primary 每屏最多一个。
- Components：`ZouAppShell`、`ZouSafeArea`、`ZouNavigationBar`、`ZouTabBar`、`ZouButton`、`ZouSheet`、`ZouToast`、`ZouPlanCard`、`ZouCommunityCard`、`ZouTripCard`、`ZouAvatar`、`ZouDaySelector`、`ZouLocationNode`、`ZouAssistantBot`、`ZouRouteCharacter`。
- 所有按钮/icon 视觉可小，交互盒必须44×44；滚动条默认隐藏但保留键盘/触控滚动。
